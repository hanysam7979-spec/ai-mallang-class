# AI 말랑 컴퓨터 교실 (MALLANG CLASS) v3 pixel

픽셀 감성의 교실형 웹앱입니다. 학생이 반과 이름을 입력하면 **번호 자리**로 안내되고, 교실에서 아바타로 이동하며 미니게임 5종을 즐길 수 있습니다. 서버 없이도 **로컬 데모 모드**로 완전히 동작하고, Supabase 키를 넣으면 **실시간 동기화 모드**로 바뀝니다.

## 로컬에서 실행

```bash
cd ai-mallang-class
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 파일로 바로 열면( file:// ) 브라우저 보안 정책 때문에 에셋 일부가 막힐 수 있으니, 위처럼 **로컬 서버**로 열어 주세요.

## 바꿔 넣는 곳 3가지

### 1) Supabase URL / Key — 실시간 접속

- **코드 기본값**: `js/config.js` 의 `CC.defaultSettings()` 안

  ```js
  supabaseUrl: '',   /* ← SUPABASE_URL  (예: https://xxxx.supabase.co) */
  supabaseKey: '',   /* ← SUPABASE_ANON_KEY */
  ```

- **앱 안에서**: 교사로 입장 → [교사 설정] → **실시간 연결** 탭 → `SUPABASE_URL`, `SUPABASE_ANON_KEY` 입력 → **연결하고 저장** (이 브라우저에 저장됨)
- **주소로 넘기기**: `http://내주소/?sbUrl=https://xxxx.supabase.co&sbKey=eyJhbGci...`
  → 값을 읽어 저장한 뒤 주소창에서는 자동으로 지웁니다.
- 비워 두면 **로컬 데모 모드**(가상 친구들과 동작)로 바로 시작합니다.

### 2) 선생님 이름 · 비밀번호

- `js/config.js` 의 `teacherName`(기본 `하니쌤`), `teacherPw`(기본 `1234`)
- 앱 안에서 바꾸려면 [교사 설정] → **비밀번호** 탭

### 3) 학생 명단 (반 · 번호 · 이름)

- 기본 데모 명단: `js/config.js` 의 `CC.DEMO_NAMES`(42명) · `CC.makeDefaultRoster()`
- 실제 학급은 [교사 설정] → **명단(엑셀 업로드)** 에서 `.xlsx` / `.xls` / `.csv` 업로드
  (첫 줄: `반, 번호, 이름` — 모달의 **명단 양식 내려받기**로 서식 확인)
- 업로드한 명단·설정은 각 브라우저의 `localStorage`(`cc.roster.v3`, `cc.settings.v3`)에 저장됩니다.

## 🎮 틈새 놀이터 (수업 후 5~10분)

교실 상단의 **🎮 틈새 놀이터** 버튼(또는 사이드바의 같은 카드)으로 들어갑니다.
`playground.html` 은 교실(`index.html`)과 **완전히 분리된 페이지**라, 실시간 세션·교실 게임 로직에
영향을 주지 않고 언제든 `← 교실로` 돌아올 수 있습니다.

```
playground.html 마무리 타이머 · 놀이 5종 · 최고 기록
css/playground.css
js/playground/
├── core.js          공통 (내 정보·효과음·타이머·랭킹·화면 전환)
├── scenes.js        SVG 그림 (틀린 그림 3장면 · 숨은 그림 3장면 · 숨은 물건 아이콘)
├── game-chosung.js  🔤 초성 퀴즈 (동물·음식·학교·컴퓨터 57문제, 힌트 2단계, 콤보 점수)
├── game-typing.js   ⌨️ 타자 놀이 (산성비식 낱말, 하트 3개, 레벨업, 타/분)
├── game-maze.js     🌀 미로 찾기 (매번 새 미로 · 초급/중급/고급 · 방향키·WASD·화면 버튼)
├── game-spot.js     🔍 틀린 그림 찾기 (3장면 × 다른 곳 5개, 동그라미·힌트 2회)
├── game-hidden.js   🕵️ 숨은 그림 찾기 (3장면 × 숨은 물건 7개)
└── main.js          허브 · 내 정보 · 첫 방문 안내
```

- **마무리 타이머**: 위쪽 `5분 / 10분` → `시작`(일시정지·초기화). 시간이 끝나면 부드러운 종소리와
  “틈새 놀이 시간이 끝났어요! 자리 정리해요~” 배너가 뜹니다. 소리는 `🔊` 버튼으로 끕니다.
- **내 정보 연동**: 교실에 입장한 이름·반(`cc.last.v3`, `cc.roster.v3`)을 자동으로 읽어 오고,
  오른쪽 위 이름 버튼에서 직접 바꿀 수도 있습니다.
- **최고 기록**: 게임별·종합(게임별 최고점 합) 순위를 `localStorage`(`cc.playground.scores.v1`)에
  저장합니다. Supabase 표가 없어도 **오류 없이** 이 컴퓨터 저장 모드로 동작합니다.

### (선택) 반 전체가 같은 랭킹을 보게 하려면

Supabase SQL Editor에서 아래 표를 한 번 만들어 두고, 놀이터의 **[공유 설정] → 공유 켜기**를 누르면
같은 교실 여러 PC의 기록이 함께 보입니다. (표가 없으면 자동으로 이 컴퓨터 저장 모드로 돌아갑니다.)

```sql
create table if not exists public.playground_scores (
  id bigint generated by default as identity primary key,
  game text not null,
  name text not null,
  class text not null,
  score int not null,
  detail text,
  created_at timestamptz default now()
);
alter table public.playground_scores enable row level security;
create policy "누구나 읽기" on public.playground_scores for select using (true);
create policy "누구나 쓰기" on public.playground_scores for insert with check (true);
```
